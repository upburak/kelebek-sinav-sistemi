# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Okunaklı tipografi, dengeli derinlik (önce kenarlık, sonra yumuşak gölge), net tablolar ve listeler. Kullanıcı teknik olmayan öğretmendir: her ekranda tek bir ana iş, sıradaki adım her zaman görünür. Mevcut tema değişkenleri (`frontend/src/styles.css`, `--ks-*`; ana renk `#146b68`, vurgu `#c54210`, Inter/sistem yazı tipi) korunur.

## Banned anti-aesthetics

- Yüksek kontrastlı sınırı olmayan bulanık cam efekti (`backdrop-filter`)
- Sıradan bilgi için havada duran pastel hap etiketler
- Süs amaçlı renk geçişleri ve parlayan (neon) kenarlıklar
- Standart düğmelerde çok renkli / gökkuşağı geçişleri
- Boş ekranlarda çizgi film illüstrasyonları
- İç içe kaydırma çubukları ve giriş alanı içinde simge kalabalığı

Bilinen borç (kurulum sırasında saptandı): `frontend/src/styles.css` içinde 3 `backdrop-filter` ve 12 renk geçişi kullanımı var; ilgili ekrana dokunulduğunda veya `ux-audit` sırasında temizlenir.

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** Normal metin en az 4,5:1; büyük metin, simge ve kenarlıklar en az 3:1.
- **Touch / focus:** Tıklanabilir hedefler en az 44×44 piksel; klavye odağı her etkileşimli öğede belirgin bir çerçeveyle görünür.

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Arayüz dili Türkçedir. Açık, anlayışlı, yol gösteren cümleler; teknik terim yerine okul dili (derslik, sınıf, sınav, dağıtım). Düğmeler eylemle başlar ("Planı düzenle", "Dağıtımı başlat"). Hata iletileri kullanıcıyı suçlamaz ve bir sonraki adımı söyler.

## Icon library

- **Library:** Project SVG
- **Package / path:** `frontend/src/App.tsx` içindeki `WorkspaceIcon` (satır içi SVG yolları); harici simge paketi yok.
- **Notes:** Yeni simgeler aynı bileşene, aynı çizgi kalınlığı ve boyutla eklenir. Emoji veya metin işaretleri (✓, ⟳, ×) arayüz simgesi olarak kullanılmaz; mevcut olanlar dokunuldukça SVG'ye çevrilir.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
